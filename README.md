# Mahym Beauty Salon — booking page

Static one-page booking link for Instagram stories: pick treatments, a day and a time, and the request opens in WhatsApp (+971 52 193 4818).

- `index.html`, `style.css`, `app.js` — the page (EN / RU)
- `img/`, `fonts/` — the salon's own photos, video loop and self-hosted fonts

No build step. Deploy the repository root as a static site (Cloudflare Pages: framework preset "None", output directory `/`).
Prices, opening hours and the WhatsApp number are at the top of `app.js`.
